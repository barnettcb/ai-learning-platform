# Current Release — Guided Path and Relevance Pass 17

This release corrects the first-time path, module orientation, sequence navigation, assessment alignment, review feedback, and component relevance issues identified after hands-on review of Pass 16. It preserves the static GitHub Pages architecture, the twelve-module and thirty-six-lesson curriculum, local-only learner data, and the established professional visual system.

## Changes
- Added prominent Begin Module 1 actions to Start Here and removed the competing Home-page orientation bypass.
- Rebuilt the opening self-assessment as a saved diagnostic with a numerical score, question-level classification, preferred responses, rationales, strengths, focus areas, and direct module links.
- Consolidated all twelve module orientations into complete landing pages. Legacy `overview.html` URLs now show a short compatibility handoff instead of duplicate content or a dead end.
- Aligned previous and next navigation across lessons, applied tasks, readiness checks, and the dynamic Continue Learning link.
- Rebuilt the learning-outcomes map so every canonical lesson appears at least once.
- Corrected Module 3 and Module 4 assessment timing, strengthened Module 5 example practice, and gave all three Module 8 lessons an explicit task and readiness role.
- Sharpened the distinction between Module 1 system behavior and Module 2 deliberate-use decisions.
- Added a self-contained fictional source packet for the Module 7 information task.
- Replaced generic review counts with direct links to missed lesson checks and failed readiness checks.
- Added restrained contextual links to the relevant reference tools.
- Removed redundant applied-task decision challenges and differentiated task effort labels.
- Added permanent regression checks for the new guided-path and relevance decisions.

## Release gate
Canonical-content, curriculum alignment, generated-output consistency, full-path navigation, diagnostic persistence, direct review feedback, reference integration, responsive layout, JavaScript syntax, browser behavior when available, GitHub Pages structure, documentation alignment, and ZIP-integrity checks must pass before delivery.
