# Lesson 8 — What Context Should I Provide?

## Outcome
You can supply the background AI needs while leaving out information that does not affect the result.

## Direct answer
Context is information that changes what a good answer should be.

Useful context may include:
- the current situation;
- relevant facts;
- what has already been tried;
- available resources;
- priorities;
- the learner's level of knowledge;
- the stage of the work;
- definitions or terms specific to the situation.

The goal is not maximum detail. The goal is enough relevant detail to prevent avoidable guessing.

## The relevance test
For each detail, ask:

> Would a different value change the answer?

If yes, the detail is probably relevant. If no, it may be unnecessary.

For example, a travel-planning request may need budget, dates, travelers, mobility needs, and preferred pace. It probably does not need the story of every prior vacation.

## Worked example
### Result
“Create a simple strength-training plan.”

### Missing context
The AI does not know the learner's experience, equipment, schedule, injuries, or goals.

### Useful context
“I am a beginner. I can train twice a week for 45 minutes. I have access to weight machines and want a simple full-body routine. I have already been cleared to exercise.”

Each detail changes the plan. That makes it relevant.

## Best practice
Provide the facts that affect the answer, then stop. Add more only when the first response reveals a real gap.

## Common failure
Learners confuse context with autobiography. Long background can hide the facts that actually control the result.

## Guided practice
Which details are likely relevant to a request for a weekly meal plan?

- Number of people
- Food allergies
- Favorite television show
- Budget
- Cooking time
- Available kitchen equipment
- Childhood hometown

Likely relevant: number of people, allergies, budget, cooking time, and equipment. The other details matter only if they genuinely affect the request.

## Independent application
Return to the result you wrote in Lesson 7. Add three to six facts that would materially change a good answer. Remove any detail that is merely interesting.

## Completion check
You are ready to continue when you can explain why each included fact affects the answer.
