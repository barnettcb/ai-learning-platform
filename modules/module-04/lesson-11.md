# Lesson 11 — When Should I Break a Task Into Steps?

## Outcome
You can divide complex work into stages when one large request would hide decisions, errors, or missing information.

## Direct answer
Break a task into steps when later work depends on choices or facts that should be reviewed first.

A single prompt works well for a focused task. A staged conversation works better when the task contains several different kinds of reasoning.

## Signals that a task needs stages
Use stages when the AI must:
- interpret a large amount of information;
- make important assumptions;
- compare alternatives before choosing one;
- produce a long or high-impact final result;
- use output from one activity as input to another;
- pause for human judgment before continuing.

## A simple staging pattern
1. **Understand:** summarize the situation and identify missing information.
2. **Plan:** propose an approach or outline.
3. **Produce:** create the requested result after the approach is accepted.
4. **Review:** check the result against the stated requirements.

Not every task needs all four stages.

## Worked example
### Oversized request
“Review these notes, decide what the problem is, create a project plan, assign priorities, draft the kickoff email, and make a status-report template.”

### Better sequence
1. “Organize these notes into goals, constraints, open questions, and risks. Do not create the plan yet.”
2. Review and correct the organized information.
3. “Using the corrected summary, propose a project plan with milestones and priorities.”
4. Review the plan.
5. Request the kickoff email and status template based on the approved plan.

The sequence creates useful checkpoints. It also prevents an early misunderstanding from spreading through every later deliverable.

## Best practice
Create a checkpoint wherever your judgment could change what should happen next.

## Common failure
Learners force every request into tiny steps. Excessive decomposition makes simple work slow and fragments the context.

Use the smallest number of stages that exposes the important decisions.

## Guided practice
Which task is more likely to need stages?

A. “Rewrite this paragraph in plain English.”

B. “Review a year of customer feedback, identify recurring problems, recommend priorities, and draft an improvement plan.”

Task B needs stages because the recommendations depend on how the feedback is grouped and interpreted.

## Independent application
Choose a real task with at least three activities. Mark where you need to review facts, assumptions, alternatives, or direction before AI continues.

## Completion check
You are ready to continue when the stages protect meaningful decisions rather than merely making the interaction longer.
