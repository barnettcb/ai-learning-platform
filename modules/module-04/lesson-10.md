# Lesson 10 — How Should the Answer Be Presented?

## Outcome
You can specify the intended audience, suitable tone, and useful format without overdirecting the content.

## Direct answer
Tell AI who the answer is for, how it should sound, and what form will make it usable.

These three instructions solve different problems:
- **Audience** controls the assumed knowledge and perspective.
- **Tone** controls how the language feels.
- **Format** controls how the information is organized.

## Audience first
The same subject may require very different explanations for a beginner, a customer, a manager, a child, or a technical specialist.

Compare:
- “Explain compound interest.”
- “Explain compound interest to an adult who is new to investing, using one simple numerical example.”

The second request helps AI choose the right vocabulary and depth.

## Use tone only when it matters
Useful tone instructions are concrete:
- calm and reassuring;
- professional and direct;
- warm but not overly casual;
- neutral and factual;
- persuasive without exaggeration.

Avoid long lists of overlapping adjectives. “Professional, polished, sophisticated, authoritative, compelling, engaging, and elegant” creates more ambiguity than clarity.

## Choose a format that matches the task
Useful formats include:
- a short explanation;
- a comparison table;
- numbered steps;
- a checklist;
- an email draft;
- an agenda;
- questions to ask;
- a decision summary.

Do not request a table merely because tables look organized. Use one when the information benefits from side-by-side comparison.

## Worked example
### Unshaped request
“Explain the project delay.”

### Shaped request
“Explain the project delay for a client who does not know our internal process. Use a calm, accountable tone. Write a brief email with three parts: what happened, what we are doing, and the revised next step.”

The request does not dictate every sentence. It defines the conditions that make the response useful.

## Best practice
Specify audience and format whenever either would materially change the answer. Add tone when the social effect of the wording matters.

## Common failure
Learners use formatting instructions to compensate for an unclear assignment. A perfectly formatted answer can still solve the wrong problem. Define the result first.

## Guided practice
Improve this request:

“Tell people about the new scheduling process.”

One possible revision:

“Explain the new scheduling process to field employees who need to know what changes on Monday. Use plain language and a direct, respectful tone. Present the answer as a one-page notice with sections for what is changing, what employees must do, and where to ask questions.”

## Independent application
Return to the task brief from Module 3. Add only the audience, tone, and format instructions that make the result more usable.

## Completion check
You are ready to continue when the requested presentation fits the real reader and task rather than reflecting a generic preference for polished output.
