# Module 12 — Manage Ongoing Work

## Module promise
By the end of this module, you can organize sustained AI-assisted work, preserve the right context across sessions, and define a personal workflow that remains understandable and controllable.

## Prerequisites
Modules 5, 9, and 11.

## Lessons
1. Manage long-running projects
2. Preserve context and create handoffs
3. Create a personal AI workflow

## Completion task
Design and document a durable workflow for one recurring or multi-session project.

## Scope
This module does not require autonomous agents or background execution. You remain responsible for directing, reviewing, and continuing the work.
