# Module 2 — Use AI Deliberately

## Module promise
By the end of this module, you can decide whether AI belongs in a task, identify situations that require another source of help, and protect sensitive information before sharing it.

## Prerequisites
Module 1, especially the distinction between useful assistance and dependable authority.

## Lessons
1. When AI is useful
2. When AI should not be used
3. Privacy, sensitivity, and safe sharing

## Completion task
Apply a deliberate-use decision process to four realistic situations. For each one, decide whether to use AI normally, use AI with safeguards, use another source first, or not use AI for the task. Then explain the reason and safest next step.

## Scope
This module focuses on whether and how to use AI responsibly. Detailed prompt construction and source-verification methods are taught later.
