# Lesson 26 — How Should I Work With Uploaded Files?

## Outcome
You can give AI a clear job for an uploaded file, account for file limitations, and review outputs against the original material.

## Direct answer
Treat an uploaded file as source material, not as proof that the AI has read every element correctly.

AI may be able to work with:
- text documents;
- spreadsheets;
- presentations;
- PDFs;
- scanned pages;
- structured data;
- multiple related files.

Results depend on file quality, format, length, layout, and whether text, tables, images, or annotations were captured correctly.

## Tell the AI how to use the file
A strong file request states:
- which file or section matters;
- the task to perform;
- the required output;
- the fields or details to preserve;
- whether outside information is allowed;
- how to handle unreadable or missing content.

Example:

“Using only the uploaded budget workbook, list recurring expenses by frequency and amount. Do not assume the existing categories are correct. Flag ambiguous transactions instead of assigning them silently.”

## Inspect before relying
For important work, begin with a file check.

Ask the AI to identify:
- available pages, sheets, or sections;
- unreadable areas;
- missing attachments;
- broken tables;
- unexpected blank content;
- whether formulas or comments are visible.

This prevents a polished answer from hiding incomplete access.

## Use location references
Request page numbers, sheet names, row labels, headings, or quoted text when the output must be traceable.

Example:

“Extract every deadline from the uploaded proposal. Include the page number, the responsible party if stated, and the exact sentence supporting each deadline.”

## Worked example
### Weak request
“Analyze these files.”

### Better request
“Compare the two uploaded vendor proposals. Extract price, included scope, exclusions, schedule, warranty, payment terms, and open assumptions. Cite the page or section for every entry. Do not rank the vendors until the comparison table is complete.”

The revised request defines both the evidence and the sequence of work.

## Best practice
Use the smallest relevant file set and verify high-impact findings in the original file before acting on them.

## Common failure
Learners upload many files without explaining their relationship. The AI may combine versions, overlook the controlling document, or treat an outdated file as current.

## Guided practice
Improve this instruction:

“Read all these project files and tell me what is going on.”

One possible revision:

“First list each uploaded file, its apparent date, and its purpose. Then identify which document appears to contain the current schedule, budget, decisions, and unresolved issues. Do not merge conflicting information; show the conflict and cite both locations.”

## Independent application
Choose one file-based task. Write an instruction that defines the file scope, expected output, traceability method, outside-information boundary, and treatment of unreadable content.

## Completion check
You are ready to continue when you confirm what the system could actually read before trusting a file-based conclusion.
