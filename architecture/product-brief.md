# AI Learning Platform — Product Brief

## Mission
Create a website-first, platform-neutral self-study system that teaches adults with basic computer literacy how to work effectively, critically, and confidently with modern AI systems.

## Basis of design
ChatGPT is the primary interaction model for examples, but core instruction must remain transferable to other mainstream conversational AI systems.

## Core outcome
Learners can decide when to use AI, frame a task, provide useful context, guide an interaction, evaluate the result, verify important claims, protect sensitive information, and convert successful interactions into repeatable workflows.

## Scope
Included: prompting, iterative collaboration, research, writing, planning, analysis, file use, image use, web-connected work, evaluation, verification, privacy, long-running projects, tool selection, and knowing when not to use AI.

Excluded from the foundational product: programming instruction, APIs, automation frameworks, agent engineering, model architecture, prompt hacks, and vendor-specific feature catalogs.

## Product form
Primary: responsive learning website.
Secondary exports: handbook, workbook, prompt/reference library, quick-reference guides, and printable exercises.
