# Editorial Standard

1. Every core concept has one canonical home.
2. Later content links back rather than reteaching.
3. Each lesson answers one primary question.
4. Use the simplest accurate explanation.
5. Practical use precedes technical explanation.
6. Recommendations are direct and specific; exceptions are stated only when they materially matter.
7. Examples must add learning value rather than merely vary the topic.
8. Every lesson must include an observable learner action.
9. Avoid model numbers, transient interface details, and vendor claims unless isolated in maintainable notes.
10. Run accuracy, redundancy, simplicity, dependency, accessibility, and future-proofing reviews before release.
