# Content Model

## Canonical content types
- Course part
- Module
- Lesson
- Worked example
- Guided practice
- Independent challenge
- Best practice
- Decision guide
- Checklist
- Template
- Prompt pattern
- Case study
- Reference article
- Glossary entry
- Safety note

## Reuse rule
A concept is authored once. Other pages reference or embed the canonical object. Adaptations may change presentation but not create competing explanations.

## Required lesson fields
- Learner question
- Outcome
- Prerequisites
- Core explanation
- Example
- Guided practice
- Independent application
- Common failure
- Completion check
- Related canonical concepts
