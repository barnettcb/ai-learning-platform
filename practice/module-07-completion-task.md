# Module 7 Completion Task — Build a Traceable Information Brief

## Scenario
A neighborhood association is reviewing three supplied items about a proposed community improvement: a written proposal, a cost table, and an annotated site image.

[Open the fictional source packet](module-07-source-packet.html) before completing the worksheet. Use only that packet unless the instructions explicitly ask for outside information.

## Instructions
Create a concise information brief that:
1. lists what each source contains and any access or readability limitation;
2. extracts the proposed scope, stated cost, schedule, responsibilities, and exclusions;
3. cites the page, section, table location, or visible image region supporting each key item;
4. summarizes the proposal for residents without omitting decision-relevant qualifications;
5. separates source facts, visual observations, and reasonable interpretations;
6. flags contradictions, missing information, and unreadable details;
7. avoids outside facts unless explicitly labeled and requested.

## Evaluation criteria
A successful submission:
- chooses extraction, summary, and interpretation deliberately;
- preserves important qualifications;
- provides traceable references;
- does not disguise missing content;
- distinguishes what the image shows from what it may suggest;
- remains usable by a reader who has not opened the original files.

## Required review note
Name one detail that could easily have been lost in a general summary and explain how the chosen output structure preserved it.
