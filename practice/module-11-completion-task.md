# Module 11 Completion Task — Turn One Success Into a Reusable Workflow

## Choose a recurring task
Select an AI-assisted task you expect to repeat, such as preparing an update, comparing options, planning an event, reviewing a document, or learning a topic.

## Required deliverables
Create:
1. a reusable prompt framework with descriptive placeholders;
2. a short input or output template, if structure is needed;
3. a review checklist matched to the task's risk;
4. adaptation notes explaining when the workflow must change;
5. a final ownership statement naming who approves real-world use.

## Test the workflow
Run or mentally test it against two different examples. Confirm that it can adapt without carrying stale facts from the first case.

## Evaluation criteria
A successful submission:
- preserves useful structure without freezing old assumptions;
- distinguishes template fields from review checks;
- includes current verification where necessary;
- remains short enough to use consistently;
- identifies conditions requiring professional or human review;
- produces a result that can be assessed before action.

## Required reflection
Identify one element you removed because it belonged only to the original task and one element you retained because it supports quality across cases.
