# Module 12 Completion Task — Design a Durable Project Workflow

## Choose a real project
Select a recurring responsibility or a project that will require several work sessions.

## Required deliverables
Produce:
1. a stable project objective and current scope;
2. staged deliverables with review gates;
3. a source-of-truth project record;
4. a handoff template populated with the current state;
5. a one-page personal workflow showing how AI will be used;
6. review levels and escalation conditions;
7. the next concrete action.

## Continuity test
Assume the current AI conversation disappears. Confirm that another person or new session could continue using only the project record, handoff, and referenced source files.

## Evaluation criteria
A successful submission:
- separates current decisions from discarded ideas;
- keeps authoritative evidence identifiable;
- uses AI in a defined supporting role;
- makes status and ownership visible;
- scales review to risk;
- preserves outputs outside the conversation;
- provides a clear restart point.

## Required reflection
Name one part of the workflow you expect to revise after real use and the evidence that would justify the change.
