# Website Page Patterns

## Lesson page
1. Learner question and observable outcome
2. Short key idea
3. One useful example
4. Best practice and common failure
5. Small application step
6. One decision check with immediate rationale
7. Learner completion check
8. Related concepts and next step

## Module landing page
- Module promise
- Prerequisites
- Three lesson cards
- Estimated effort stated as a range, not a guarantee
- Completion task
- Progress state

## Reference page
- Definition
- When to use it
- Short procedure
- One example
- Common mistake
- Links to canonical lesson and related tools

## Prompt pattern page
- Problem the pattern solves
- Flexible structure
- Annotated example
- Variations
- Misuse warning
- Copyable starter, clearly labeled as a starting point rather than a universal prompt

## Decision guide page
- Decision question
- Branching criteria
- Recommended action
- Escalation or verification trigger
- Link to the lesson that teaches the underlying principle

## Practice page
- Scenario
- Learner task
- Optional hints
- Model response or evaluation criteria hidden until submission
- Reflection question focused on transfer

## Search result behavior
Search should prioritize canonical lessons and references before examples. Duplicate or adapted content should never outrank its canonical source.
