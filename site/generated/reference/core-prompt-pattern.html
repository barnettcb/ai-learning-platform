Core Prompt Pattern

Use this pattern when a task needs more structure than a simple question.

Pattern

Outcome: State what you need.

Context: Include the facts or background that change the answer.

Constraints: State limits, requirements, exclusions, and deadlines.

Audience and format: Identify who will use the result and how it should be presented.

Source basis: Supply files or request current, authoritative sources when accuracy depends on them.

Review instruction: Ask the AI to identify assumptions, uncertainties, or items requiring verification when those matter.

Example

Create a one-page comparison of the three attached service proposals for a homeowner. Compare total price, scope, exclusions, warranty, and schedule. Do not assume missing terms are included. Flag unclear language and list the questions that should be resolved before selection.

Best practice

Use only the elements the task actually needs. This is a flexible pattern, not a form that must be completed every time.
