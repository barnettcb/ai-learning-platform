Module 2 — Use AI Deliberately

Module promise

By the end of this module, learners can decide whether AI belongs in a task, identify situations that require another source of help, and protect sensitive information before sharing it.

Prerequisites

Module 1, especially the distinction between useful assistance and dependable authority.

Lessons

  1. When AI is useful
  2. When AI should not be used
  3. Privacy, sensitivity, and safe sharing

Completion task

Apply a simple decision process to five realistic situations. For each one, decide whether to:

  • use AI normally;
  • use AI with safeguards;
  • use another source first; or
  • not use AI for the task.

Then explain the reason and the safest next step.

Deliberate exclusions

This module does not teach detailed verification, professional-domain workflows, or prompt construction. Those concepts have separate canonical homes.
